# Technologies for Artificial Intelligence

Course material for **Technologies for Artificial Intelligence**, first-year MSc in
Computer Science, Università degli Studi dell'Aquila — autumn 2026.

Ten lessons of three hours, every Friday from 25 September to 27 November 2026.

> A first course in machine learning for people who can already program: the methods,
> the mathematics underneath them, and the experimental discipline to tell a result
> that holds from one that only appears to.

---

## Students start here

1. [**Prerequisites**](Course/PREREQUISITES.md) — what you need to know before Lesson 1
2. [**Getting started**](Course/Setup/Docker_Quickstart.md) — Docker setup, 15 minutes
3. [**Schedule**](Course/SCHEDULE.md) — dates and what each lesson covers
4. [**Syllabus**](Course/SYLLABUS.md) — aims, outcomes, assessment
5. [**Assessment**](Assessment/) — project brief, exam structure, criteria

New material appears on the day of each lesson. Run `git pull` to get it.

**No API keys, no paid accounts, no GPU.** Every notebook in this course runs offline
on a laptop CPU.

## What is in each lesson

| Folder | Contents |
|---|---|
| `Docs/` | The handout: the reference text, with complete mathematical derivations |
| `Slides/` | Lecture slides (`.pptx`, built from markdown) |
| `Notebooks/` | Runnable implementations |
| `Quizzes/` | Self-check questions with collapsible answers — not graded |
| `Exercises/` | The assessed weekly exercise |
| `Figures/` | Figures, each generated by a notebook cell |

Slides and notebooks are published on the day of the lesson; the handout follows by
the Monday after, since it is study material rather than lecture support.

## Course structure

| # | Date | Lesson |
|---|---|---|
| 1 | 25 Sep | Introduction and the machine learning workflow |
| 2 | 2 Oct | Data: exploration and preparation |
| 3 | 9 Oct | Regression |
| 4 | 16 Oct | Classification and evaluation metrics |
| 5 | 23 Oct | Experimental methodology and model selection |
| 6 | 30 Oct | k-NN, Naive Bayes and support vector machines |
| 7 | 6 Nov | Trees and ensembles |
| 8 | 13 Nov | Unsupervised learning |
| 9 | 20 Nov | Neural networks |
| 10 | 27 Nov | Convolutional networks and course synthesis |

Large language models, transformers, RAG and agents are **not** covered — they belong
to a separate course in the programme. [`Course/BRIDGE.md`](Course/BRIDGE.md) is a
reading for students going on to it: what this course leaves them holding, and what
it turns into there.

## For instructors

Build slides and handouts from their markdown sources:

```bash
python tools/build.py
```

Rebuild the slide template after a change to the visual identity:

```bash
python tools/make_template.py
```

Publish a new student image (`VERSION` is the single source of truth):

```bash
python tools/release.py patch --dry-run
```

Conventions, audience assumptions and content rules are in [`CLAUDE.md`](CLAUDE.md).

## Docker image

Two images, because TensorFlow is 1.3 GB that nothing before Lesson 9 needs:

```
fabioantonini/technologies-for-artificial-intelligence:core    lessons 1-8
fabioantonini/technologies-for-artificial-intelligence:full    adds TensorFlow, lessons 9-10
```

`full` is built **from** `core`, so a student who already has `core` downloads only
the TensorFlow layer when November arrives. `docker-compose.yml` reads the tag from
`.env`, which ships set to `core`; versioned tags such as `0.1.0-core` exist for
reproducibility. There is deliberately no `:latest` — with two images the name has no
honest meaning.

The image carries the **environment**. Course content reaches students through
`git pull`, so the image is only republished when dependencies change.
